## 2. 本次大改的口径

**做什么**：以官方红果短剧 7.4.5.32 为唯一视觉与结构基准，重做手机端的导航、剧场、推荐、我的、播放、搜索；同步拆掉 50KB 级单体文件与四层 CSS 覆盖。

**不做什么（A 档，写死）**：福利/金币/提现、广告与曝光上报、商城、游戏、社区动态、订单、支付/会员；青少年模式暂不做。

**可以做、但不进本次（C 档，单独立项）**：推送、热修复、多进程、Lynx/H5 动态页、小说/听书/漫画/POV 文本。这五项已从"禁止"改为"预留扩展位"，架构上按《开发文档》§1.2 的扩展位约定留好接口前缀、路由、页面目录与数据表，**但不在本轮实现**。

**两条线分开**：

| 线 | 内容 | 状态 |
| --- | --- | --- |
| A 线 | 运行时独立化（内置 Node + 手机 ffmpeg） | **必做（发布阻断）**；"手机独立运行"是硬要求，1.1.0 需补 ffmpeg 重编并上真机，不达标不发版 |
| B 线 | 界面与信息架构官方对齐 | **本次主线** |

两条线同一版本内都要达标：UI 是「看起来对」，独立运行是「用起来能活」。

**通过标准**（任一不满足不算完成）：

1. 底栏 4 个纯文字 Tab（首页/剧场/追剧/我的），无图标、无药丸、无角标 —— **✅ 阶段 A 已达成**；
2. 推荐页视频 16:9 居中、上下黑边；
3. 剧场一屏 ≥4 卡、双列瀑布流，含继续播放/爆款新剧/榜单入口混排；
4. 播放页底部只有「选集/清晰度/倍速/清屏」四控件，320 宽全见；
5. 六档视口（320×568 / 360×640 / 360×800 / 375×667 / 390×844 / 412×915）无横向溢出、固定元素不压正文 —— **✅ 阶段 A：24 张截图 0 溢出**；
6. 390×844 截图与官方同名页并排，无结构性差异。
