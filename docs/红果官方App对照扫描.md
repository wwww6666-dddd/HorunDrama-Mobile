## 1. 结论先行

1. **官方这套 UI 和我们现在的实现是两种语言**：官方是「纯文字 + 黑白灰 + 大量留白 + 信息靠海报承载」；我们是「大标题 + 玻璃质感 + 图标胶囊 + 强调色」。对照后最该改的是**导航结构**和**推荐页视频比例**，不是配色。
2. **官方底部导航只有 4 个纯文字 Tab**：`首页 / 剧场 / 福利 / 我的`，没有图标、没有独立"榜单""追剧"入口；选中态只是加粗 + 变白（深色底）或变黑（浅底）。
3. **官方推荐页视频是 16:9 居中、上下大面积黑边**，不是我们现在的 1:1 贴边满宽。这是本次扫描最直观的差异。
4. **官方有独立的"福利"页**（金币/现金/任务体系），我们完全没有。
5. **官方"剧场"页没有大标题**，顶部直接是搜索框；分类是横向文字 Tab，功能是 4 个「彩色圆图标 + 文字」胶囊；内容是**双列瀑布流**，里面混排「继续播放卡」「爆款新剧」「榜单入口」「热度值」。
6. **官方是浅色为主**：剧场/我的/搜索/福利都是白底；只有首页推荐流和播放页是纯黑。我们目前默认深色。
7. **包内不含 `res/layout`**（0 个 XML 布局），有 `assets/composeResources` → 界面是 Compose 自绘。所以"拆布局 XML 对照"这条路走不通，能用的是**截图 + 素材 + 字体 + lottie**。

## 5. 差异清单与建议顺序

### P0 —— 结构级（不改就像"另一个产品"）

1. **底部导航改 4 个纯文字 Tab**：首页 / 剧场 / 福利 / 我的；去掉图标、去掉独立「榜单」「追剧」Tab。
   - 榜单入口迁到「剧场」的 `排行榜` 胶囊 + 「搜索」页榜单区；
   - 追剧入口迁到「剧场」的 `预约/追更` + 「我的」`追更` 卡。
2. **推荐页视频改 16:9 居中**（上下留黑），右侧头像+关注贴视频右下角内侧；去掉 1:1 满宽。
3. **顶部 Tab 改文字 + 下划线**（关注/漫剧/真人剧/推荐），左侧加汉堡菜单、右侧搜索。
4. **剧场页去大标题**，改「搜索框 → 分类文字行 → 4 个彩色图标胶囊 → 双列瀑布流」；瀑布流内混排继续播放卡、爆款新剧标、榜单入口卡、热度标。
5. **「我的」重构**为：浅色渐变头 + 头像/红果号/三数字/编辑资料 + 5 个白卡入口 + 5 个内容 Tab + 二级 chips + 3 列海报网格。
6. **主题切浅色优先**：剧场/我的/搜索/福利走白底，只有推荐流与播放页纯黑。

### P1 —— 功能补齐

7. 搜索页：识剧入口、搜索历史两列 + 清空、猜你想搜 3 卡、热搜榜/热点话题榜/预约榜三 Tab。
8. 播放页：底部改「选集 ⋯ / HD 清晰度 / 1.5x / 清屏」四控件 + 细进度条；顶部「‹ 第N集」+ ⋮；收藏星做实心五角星。

## 6. 当前扫描中发现的自身问题（顺带记录）

- **上游限流**：本次给本项目拍截图时，`/api/home`、`/api/feed` 返回「上游限流了，等一两分钟再试」，剧场/推荐页截图无内容（`.tmp/shots/feed.png`、`theater.png` 均为空态）。说明抓取频率或设备档案已触发上游风控，需要加退避或换设备档案。
- 我方 tabbar 选中态用强调色（橙），官方用**字重 + 颜色反转**，视觉噪音更低。

## 7. 复现方法（下次重新采集用）

```powershell
$adb = "D:\红果短剧手机端\android-sdk\platform-tools\adb.exe"

# 1) 对齐手机基准（392×851dp）
& $adb shell "wm size 1080x2340; wm density 440"

# 2) 启动官方 App
& $adb shell "am force-stop com.phoenix.read"
& $adb shell "monkey -p com.phoenix.read -c android.intent.category.LAUNCHER 1"

# 3) 逐页截图（tap 坐标按 1080×2340；底部 Tab 在 y≈2250：首页130 / 剧场388 / 福利648 / 我的930）
& $adb shell "input tap 388 2250"; & $adb shell "screencap -p /sdcard/theater.png"
& $adb pull /sdcard/theater.png .\theater.png

# 4) 还原平板
& $adb shell "wm size reset; wm density reset"

# 5) 取原包（adb pull 不支持中文路径，先拉到 ASCII 目录再移动）
& $adb shell "pm path com.phoenix.read"      # → /data/app/~~xxx==/com.phoenix.read-yyy==/base.apk
& $adb pull "<上一步路径>" D:\hg_tmp\base.apk
```

采集时的坑：
- 首次进「剧场」会弹 **"添加到主屏幕"** 系统弹窗、以及 **"看短剧奖励待领取 704 金币"** 弹窗，都会挡住画面，需要先点「取消」/「×」再截。
- 播放页是独立全屏 Activity，`keyevent 4` 有时一次退不出去，需要连按两次。
- `adb pull` 到含中文的路径会报 `No such file or directory`，必须先拉到 ASCII 路径再 `Move-Item`。
